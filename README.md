# HQ CRM 系统（局域网共享版 · V1.5.0）

一套面向中小外贸企业的客户关系与单据管理系统，仿照当前主流外贸 CRM 的核心工作方式：
以「客户 + 跟进 + 历史报价 + 单据」为主线，覆盖从**询盘、报价、PI 形式发票、销售合同、商业发票到装箱单**的完整业务流。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 仪表盘 | 客户/单据统计、待跟进提醒、快捷入口 |
| 客户管理 | 客户按登录账号隔离；公司资料、联系人、跟进记录互不混淆，公共客户池例外 |
| **客户分层** | 按贡献值自动划分 A/B/C/D；A 类每周沟通、B 类每月简报、C 类群发、D 类停止主动联系 |
| **行业简报** | 官方 RSS/手工素材白名单、DeepSeek 草稿、人工审核、WhatsApp/邮件发送，并自动完成 B 类月度跟进 |
| **WhatsApp 收件箱** | 三栏会话工作台：未读/待绑定筛选、客户绑定、快捷回复、AI 回复草稿、图片/文件收发、按天同步跟进 |
| **WhatsApp 自动回复** | WhatsApp 页面管理员总开关；开启即启动后台 worker，关闭即停止。已置顶客户永不自动回复；现货图默认全部发送并逐张限速 |
| **每日自动回复看板** | 仪表盘实时汇总今日覆盖客户、发送消息/文件、资格追问、转人工/异常、AI 判定分布、额度使用率和最近动作 |
| **WhatsApp 广告归因** | 自动捕获客户点击 Meta Click-to-WhatsApp 广告的广告 ID、标题、落地页、`ctwa_clid` 和 `ref`，并写入会话与客户首触档案 |
| **共享知识库** | 按产品资料、报价政策、工厂资料、外贸术语和历史经验分类；支持搜索、Markdown 编辑，CRM 数据助理会附带匹配条目并列出来源 |
| 产品管理 | 品名/英文名/规格/HS 编码/单位/单价/产地，开单可直接引用 |
| **历史报价** | 与产品管理联动，记录客户历史报价、数量、单价、金额和状态；新增报价后自动生成跟进记录 |
| **单据中心** | 报价单、形式发票 PI、销售合同/订单、商业发票 CI、装箱单 PL |
| **单据模板** | 每类单据内置标准中英双语模板，可自由新建/复制/编辑排版，支持恢复系统默认 |
| 系统设置 | 公司抬头与银行信息（单据自动引用）、登录账号管理 |
| **库存管理** | 产品库存与预警值；销售订单确认先匹配库存：充足则自动扣减并记录客户，不足则拦截并在仪表盘生成待补货提醒；采购单到货自动入库 |
| **供应商管理** | 供应商资料维护；单据中心新增「采购单 PO」（内置模板，直接引用供应商） |
| **库存流水** | 每次扣减/入库/回补都记录：哪个客户采购、哪个供应商入库、对应单号与备注 |
| **Excel 导入导出** | 客户、单据批量导入/导出（Excel），单据支持勾选批量删除与按模板导入 |

### 单据中心特点
- 一张单据可随时**切换模板**并自动重新生成版式；
- 支持**占位符**：公司资料、客户、联系人、单据字段、明细行等，模板内容可完全自定义（HTML）；
- 明细区自动按商品逐行生成表格，支持中英文品名、规格、数量、单价、金额、大写金额；
- 生成后可**打印 / 另存为 PDF / 导出 Excel**，适合直接发客户或用于报关清关。
- 新建 PI 添加该客户以前采购过的同款产品时，自动参考上一次卖价并显示来源单据；手工输入的价格优先，不会被历史价覆盖。

## WhatsApp 收件箱

- 左侧「WhatsApp」进入三栏收件箱：会话列表、聊天窗口、客户与跟进；
- 新消息显示未读角标，打开会话自动清除；支持全部/未读/待绑定/已绑定筛选及姓名、号码、客户搜索；
- 未绑定会话可按号码自动匹配当前账号客户，也可一键新建客户；公共池客户按共享规则匹配；
- 支持快捷回复、DeepSeek 回复草稿、图片/视频/语音/文件收发与预览；
- 可按天把聊天幂等同步到客户跟进，重复同步只改写 WhatsApp 汇总，不删除手工跟进；
- AI 草稿只填入输入框，必须人工核对后发送，不开放自动群发。

> WhatsApp 通道使用非官方协议 Baileys，主号直连存在封号风险；请优先使用业务副号并保持本机代理稳定。

## 如何启动

1. 安装 [Node.js](https://nodejs.org/)（22 或更高版本，作者在 24 上测试通过）；
2. 双击 **`启动系统.bat`**；
3. 终端会显示两个地址，任选其一在浏览器打开：
   - 本机：`http://127.0.0.1:5000`
   - 局域网：`http://<这台电脑的IP>:5000`（如 `http://192.168.1.100:5000`）
4. 默认账号：
   - 管理员：`admin` / `admin123`
   - 业务员：`sales` / `sales123`
   （首次登录后请在「系统设置」修改密码）

## 让同事在局域网内访问

- 确保所有电脑与服务器电脑在**同一局域网**（同一路由器/Wi-Fi）；
- 服务器电脑需允许防火墙放行端口 5000。以管理员身份运行一次：

```bat
netsh advfirewall firewall add rule name="CRM-5000" dir=in action=allow protocol=TCP localport=5000
```

- 把终端里显示的 `http://192.168.x.x:5000` 发给同事，用浏览器打开即可（无需安装任何软件）；
- 同一时间多人登录各自账号使用；所有数据保存在本机 `data/crm.db`，请定期备份该文件。

## 模板自定义快速上手

1. 打开「单据模板」，选择某一类型；
2. 点「编辑」修改系统内置模板，或「复制」后改自己的版本；
3. 编辑器右侧有**占位符清单**与**实时预览**；
4. 明细行区域写法：

```html
<!-- ITEMS:BEGIN -->
<tr>
  <td>{{item.seq}}</td>
  <td>{{item.name}}</td>
  <td>{{item.qty}}</td>
  <td>{{item.price}}</td>
  <td>{{item.amount}}</td>
</tr>
<!-- ITEMS:END -->
```

常用占位符示例：`{{company.name}}`、`{{customer.company_name}}`、`{{contact.name}}`、`{{doc.doc_no}}`、`{{doc.total_amount}}`、`{{doc.total_amount_cn}}`（中文大写金额）。

## 默认端口与配置

默认端口 5000，如需修改：新建环境变量 `PORT`，或在命令行执行 `set PORT=8080` 后再启动。

## Excel 导入导出 / 库存说明（v1.1 新增）
- 客户管理页：「导出当前客户」「下载导入模板」「导入 Excel」（同名客户自动更新，可带主要联系人）；
- 单据中心页：可**勾选**多张单据导出或批量删除；也支持下载模板后批量导入（明细格式：`品名|数量|单价|单位`，多条用分号分隔）；
- 库存：产品管理页直接看库存/预警并快捷**入库/出库**；销售合同确认后自动扣库存，退回草稿/作废自动回补；
- 系统新增 Excel 读写组件（已内置在项目 node_modules 中）。若整体拷贝到别的电脑运行，请连 node_modules 一起拷贝；如提示缺少组件，在项目目录执行一次 `npm install --registry=https://registry.npmmirror.com` 即可。
