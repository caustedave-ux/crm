# WhatsApp 广告来源归因（V1.11）

## 能识别什么

客户点击 Meta Click-to-WhatsApp 广告后发来的首条消息，WhatsApp 会在消息 `contextInfo.externalAdReply` 中回传广告信息。系统会保存：

- 广告 ID：`sourceId`，可在 Meta 广告后台定位具体广告；
- 广告标题、正文；
- 广告落地页 `sourceUrl`；
- 点击 ID：`ctwaClid`；
- 广告链接中的 `ref` 参数；
- 首次进入时间；
- 原始归因 JSON 快照。

## 首次归因规则

- 客户第一次通过广告进入时，首触广告写入 WhatsApp 消息、会话和客户档案。
- 同一客户后续再从另一条广告进入，不覆盖第一次广告来源。
- 只记录客户发来的消息，不记录业务员发出的消息。
- 客户从 WhatsApp 会话自动匹配或手动绑定后，广告信息自动写入客户档案。
- 从 WhatsApp 新建客户时，也同样写入广告来源。

## 广告名称映射

Meta 回传的广告 ID 是数字编号。可在 WhatsApp 会话的广告条中点击“标记广告”，填写：

- 业务易读名称；
- 广告系列；
- 广告组；
- 投放备注。

映射按登录账号隔离。同一广告 ID 进入的其他客户会自动显示相同名称。

## 数据表

- `wa_messages.ad_*`：记录每条客户消息携带的广告回传。
- `wa_chats.ad_*`：记录每个 WhatsApp 会话的首次广告来源和最近广告触达时间。
- `customers.ad_*`：记录客户首次广告来源，用于后续统计和客户档案。
- `wa_ad_sources`：广告 ID 到业务名称、广告系列、广告组的映射。

## 注意

- 只能捕获接入新版本后收到的新广告消息。旧消息若数据库中未保存 `externalAdReply`，无法事后恢复广告 ID。
- 广告 ID 可直接复制到 Meta Ads Manager 搜索定位。
- 若 WhatsApp 未回传广告 ID，只能显示标题、落地页或点击 ID，不能用点击 ID 代替广告 ID。
