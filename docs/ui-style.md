# UI 视觉规范（纸墨台账）

> 2026-10 改版。全站只有一套视觉语言，改动前先看这页，别再往 `style.css` 里加"临时覆盖"。

## 一、为什么是这套

改版前的病：**三种强调色同时抢**（珊瑚橙 / 警示黄 / 深黑渐变）、**六种圆角**（8–18px 混用）、**三层阴影**叠加。
结果每个区块都在喊"看我"，放在一起就不协调。

纸墨台账的逻辑：**这是一本天天翻的贸易台账，不是海报。**
层级靠字号、字重、留白和发丝线，不靠颜色和投影；强调色只有一个。

## 二、令牌（`static/css/style.css` 的 `:root`）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--neo-bg` | `#f6f4ef` | 页面底色（暖纸） |
| `--neo-surface` | `#fffdfa` | 卡片 / 顶栏 / 侧栏 |
| `--neo-surface-2` | `#faf8f3` | 次级底（表头、hover、输入框） |
| `--neo-ink` | `#1b1a17` | 正文与标题（墨） |
| `--neo-muted` | `#6d675b` | 次要文字 |
| `--neo-muted-2` | `#968f81` | 辅助文字 / 占位 |
| `--neo-line` | `#e7e1d5` | 发丝线（1px，唯一的分隔手段） |
| `--neo-line-strong` | `#d6cfc0` | 输入框、描边标签的边框 |
| `--neo-coral` | `#1f4d3d` | **唯一强调色**：墨绿（主按钮、选中态、可交互） |
| `--neo-radius` | `10px` | 卡片圆角；按钮 8px、小按钮 6px |
| `--neo-shadow` | `none` | 卡片不投影 |

## 三、五条硬规矩

1. **不引入第二个强调色**。要突出一件事，用墨绿实心或加字号，不要换颜色。
2. **不再加投影**。需要分层用 `--neo-line` 的 1px 线。
3. **圆角只用三档**：卡片 `--neo-radius`、按钮 8px、小元素 6px。
4. **状态用描边标签**（`.badge` 默认透明+边框）；只有逾期/异常/完成才给低饱和底色。
   实心黑标签只留给"最需要一眼看到"的东西。
5. **数字用 `tabular-nums`**（已全局生效），表格金额列不要用等宽字体以外的字体。
