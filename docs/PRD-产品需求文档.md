## 1. 产品概述

HQ CRM系统是一套面向外贸业务全流程的管理系统，覆盖「客户开发 → 跟进 → 报价/单据 → 采购/库存 → 发货 → 收款」的完整链路。系统支持自定义模板的单据中心、局域网多账号协作、微信内网页访问，并可部署到云服务器长期使用。

### 1.1 产品定位

- 定位：轻量、开箱即用、可私有化部署的外贸业务管理系统。
- 形态：Web 系统；支持电脑浏览器、手机浏览器、微信内网页（H5）访问。
- 数据：默认 SQLite 单文件数据库，自动备份；支持整库迁移到云服务器。
- 扩展：CRM 数据助理使用 Codex CLI；WhatsApp 与行业简报等生成能力继续使用 DeepSeek。

### 1.2 目标用户与场景

| 用户角色 | 主要场景 |
|---|---|
| 外贸业务员 | 维护客户与联系人、记录跟进、创建报价单/PI/合同、跟踪发货与收款 |
| 外贸主管 / 老板 | 查看仪表盘经营数据、异常提醒、团队跟进情况、客户资源池分配 |
| 单人多角色（SOHO） | 一人完成客户、产品、单据、库存、收款全流程 |

## 2. 名词解释与角色权限

| 名词 | 说明 |
|---|---|
| 客户 | 客户公司档案（国家、联系方式、图片、状态、级别）；客户归所属业务员，公共客户池共享 |
| 跟进 | 对客户的沟通记录（方式、时间、内容、下次跟进、图片）；**按登录账号独立** |
| 公共客户池 | 取消跟进或超期未跟进的客户进入的共享池，所有账号可见、可领取 |
| 单据 | 报价单、形式发票(PI)、销售合同(SO)、商业发票(CI)、装箱单(PL)、采购单(PO) |
| 货款 | 单据的定金、尾款、已付、未付；支持分笔收款（金额+收款时间） |
| 库存流水 | 库存每一次变动的记录（客户采购扣减、采购入库、发货回补、手动调整） |
| 异常客户提醒 | PI 到期未发货、发货后未收尾款、PI 与采购单产品不匹配 |

### 2.1 账号与权限

- 系统支持多账号；账号由管理员在「系统设置」中创建 / 停用。
- 客户资料按业务员隔离，公共客户池共享；产品、单据、库存按现有业务规则共享；「跟进记录」**按账号独立**。
- 公共客户池对所有登录账号可见，任意账号可领取。

## 3. 功能需求

### 3.1 仪表盘

| 功能 | 需求说明 |
|---|---|
| 经营统计 | 客户总数、本月新增、进行中商机与金额、赢单金额、本月单据与金额 |
| 待办（随手记） | 快速记录待办事项，可勾选完成 / 删除（历史功能，可按需启用） |
| 最近单据 | 展示最近创建的单据（可选面板） |
| 待跟进提醒 | 仅显示当前账号「今天 / 明天」的跟进；每条可点击展开该客户最近一个月跟进内容；点击别处自动收起；可一键「完成」 |
| 强提醒（29 天） | 满 29 天未跟进的客户红色面板提醒：客户、最后跟进时间、未跟进天数、电话；提供「立即跟进」「放入公共池」 |
| 待发货订单 | 已收款（含仅收定金）但未填写发货日期的 PI，列出客户 / 单号 / 交货期 / 金额 / 已收，可去发货 |
| 待收款订单 | 货款未收齐的销售订单（PI / 销售合同 / CI）：显示金额、定金、已付、欠款，提供「登记收款」「去发货」 |
| 异常客户提醒 | ① 交货期已到未登记发货；② 已发货但尾款未清；③ PI 产品与采购单明细无法匹配（优先按产品编号，其次按品名 / 型号文字） |

### 3.2 客户管理

| 功能 | 需求说明 |
|---|---|
| 客户档案 | 公司名称、英文名称、国家/地区、地址、网站、行业、状态、级别、联系电话（国际区号+号码）、传真、邮箱、WhatsApp、微信、客户来源、备注、客户主图 |
| 国家自动识别 | 按国际区号自动生成国家/地区；内置 195 个国家/地区区号表（+1 为美国/加拿大共用，加拿大需手动改） |
| 联系人 | 一个客户下可有多个联系人（姓名、职位、部门、电话、手机、邮箱、主联系人标记、头像图片） |
| 客户导入/导出 | Excel 批量导入（同名客户自动更新，可带主要联系人）；按条件导出 Excel |
| 批量删除 | 客户列表支持勾选批量删除（存在单据/商机的客户会被跳过保护） |
| 取消跟进 | 客户列表/详情提供「取消跟进」按钮：客户进入公共客户池（记录入池时间与原因） |
| 超期标记 | 满 29 天未跟进的客户在列表中显示红色「N 天未跟进」标记 |
| 排序/搜索 | 按公司名、英文名、国家搜索；按更新时间排序 |

### 3.3 公共客户池

- 入口：左侧菜单「公共客户池」，**所有账号可见**。
- 来源：① 手动「取消跟进」；② 满 30 天未跟进自动入池（**仅对有过跟进记录的客户生效**）。
- 列表字段：公司名称、国家/地区、电话、邮箱、入池时间、入池原因；支持搜索。
- 操作：查看客户详情；「领取」后客户回到客户管理，并自动生成一条“从公共客户池领取客户”的跟进记录（归领取人）。

### 3.4 跟进管理

| 功能 | 需求说明 |
|---|---|
| 跟进方式 | WhatsApp、邮件、微信、电话、样品（另有会议、拜访、报价、其他） |
| 跟进字段 | 跟进方式、关联商机、跟进时间、联系人、主题、下次跟进日期、跟进内容、下次跟进要点、询盘图片（可多张） |
| 独立跟进 | 每条跟进绑定所属登录账号；跟进看板、仪表盘提醒、客户/商机详情均只显示本人跟进；编辑/删除/完成仅限本人 |
| 完成流程 | 点击「完成」：旧记录自动归档（标记已完成、不再进入待跟进提醒），并立即弹出「新建跟进（今天）」弹窗；本次跟进时间默认现在，下次跟进日期可留空 |
| 集中看板 | 按客户集中查看跟进记录；支持按跟进方式筛选、关键词搜索、待跟进提醒筛选；日期颜色区分（红色过期、黄色一周内） |
| 超期规则 | 满 29 天未跟进 → 强提醒（仪表盘面板 + 菜单角标 + 客户列表标记）；满 30 天 → 自动进入公共客户池（系统启动时与每小时检查） |

### 3.5 销售机会

- 商机字段：客户、标题、金额、销售阶段、概率、预计成交日期、负责人、来源、描述、备注。
- 支持单个删除与批量删除。
- 商机详情展示关联单据与本人跟进记录。

### 3.6 产品管理

| 功能 | 需求说明 |
|---|---|
| 产品字段 | 品名、英文品名、规格型号（货号）、HS 编码、单位、产地、产品图片、当前库存、库存预警值、进货价、每箱件数、单件体积、单件重量、备注 |
| 图片 | 支持上传/更换产品图片；列表中点击图片可放大预览 |
| 复制产品 | 支持一键复制为新产品（库存归零）；复制后停留在当前页（保留分页/筛选） |
| 分类 | 按英文品名整词分类（如 panel handle、rosette handle、welding hinge、rim lock、smart lock…） |
| 排序与分页 | 支持按库存高→低 / 低→高 / 缺货优先排序；每页 15 个产品；重置旁提供页码快速跳转 |
| Excel 批量导入 | 模板含全部字段与「图片」列（可插入图片或填写图片路径/URL）；按货号匹配更新，否则新建；留空列不覆盖原值 |
| 编辑返回 | 编辑保存后返回进入前的页面（保留页码/搜索/分类/排序） |

### 3.7 库存管理

| 功能 | 需求说明 |
|---|---|
| 显示范围 | 只显示有数量的产品（含正数与负数）；可从产品管理新建产品 |
| 库存字段 | 产品图片、货号、件数/每箱、装箱数、总数量、进货价、客户平均卖价、状态 |
| 产品分类 | 按英文品名分类筛选；与搜索叠加使用 |
| 分页 | 每页 15 款；重置旁有页码下拉，表格右下角有页码导航 |
| 客户采购明细 | 点击产品可查看被哪些客户采购（数量、金额、单据） |
| V1.01 库存规则 | 库存为 0 或负数的产品被客户采购后扣减为负；完成发货后自动回补该次扣减数量；库存为正的产品采购扣减、完成发货后不回补；均可手动调整 |
| 库存流水 | 记录每一次变动（客户采购扣减、采购入库、发货回补、手动出入库），含单据、往来方、变动数与结存 |
| 库存提醒 | 侧边栏「库存管理」显示待处理库存不足角标（仪表盘库存预警已移除） |

### 3.8 单据中心

| 功能 | 需求说明 |
|---|---|
| 单据类型 | 报价单(QUO)、形式发票(PI)、销售合同(SO)、商业发票(CI)、装箱单(PL)、采购单(PO) |
| 模板 | 系统内置模板 + 自定义模板（HTML + 占位符，支持编辑与实时预览） |
| 新建/编辑 | 支持按类型、客户/供应商、模板创建；商品明细支持「按分类查找添加」与「按货号搜索添加」；添加产品自动带出每箱件数；保存时逐行读取（单价以用户输入为准） |
| 明细字段 | 序号、图片、品名（中/英）、颜色、规格型号、单位、CTN 箱数、QTY 每箱、T.T QTY 总数量、体积、总体积、重量、总重量、单价、金额、备注 |
| 计算逻辑 | CTN × QTY每箱 = 总数量；件数 × 体积 = 总体积；件数 × 重量 = 总重量；金额 = 数量 × 单价 |
| PI 特殊要求 | Description 仅显示中文品名；新增「总箱数 Total CTN」（= 各行 CTN 合计）；支持上传「备注图片」并显示在 PI 上 |
| 批量操作 | 单据支持 Excel 批量导入、导出当前列表/所选单据、批量删除 |
| 导出 Excel | 单张单据导出 Excel，版式与预览一致（含单据信息、明细、条款、签章） |
| 打印/PDF | 打印页按宽度适配（所有列在一页宽内），内容纵向自然分页且不重复；不强制压缩到单页 |

### 3.9 货款管理

| 功能 | 需求说明 |
|---|---|
| 货款列表 | 按单据跟踪：单据金额、定金、尾款、已付、未付、状态；每行提供「发货」「登记收款」 |
| 登记收款 | 支持分笔收款：每笔填写收款金额、收款时间、备注；系统自动汇总「已付」，未付 = 单据金额 − 已付；欠款醒目显示 |
| 快捷操作 | 「全额收讫」一键记一笔 = 单据金额；「添加一笔 / 删除一笔」管理分笔 |
| 历史数据 | 旧的单一「已付」金额自动转为一条历史分笔记录，金额不变 |
| 与发货联动 | 登记过收款（含仅收定金）的 PI 会进入发货管理；货款未收齐的订单显示在仪表盘「待收款订单」 |

### 3.10 发货管理

- 发货信息：仓库地址、联系方式、唛头、发货日期、仓库签收图片、验货图片。
- 列表范围：销售合同 / CI + 已登记收款（含定金）的 PI。
- 「完成发货」按 V1.01 规则回补零/负库存订单的欠货数量；可在仪表盘「待发货订单」查看已收款未发货的 PI。

### 3.11 供应商管理

- 供应商档案：名称、英文名称、国家、联系人、职位、电话、传真、邮箱、网站、地址、主营产品、付款条件、备注。
- 供应产品：每款可上传图片、填写规格型号、单位、独立报价、币种、备注；可关联「对应我方产品」（用于采购匹配 / 入库）。
- 供应商详情页可一键给该供应商开采购单。

### 3.12 AI 助理、世界地图与 WhatsApp

- Codex 助理：以当前账号可见的 CRM 数据为基础问答，通过本机 Codex CLI 调用，使用只读沙箱。
- WhatsApp 收件箱：三栏会话、未读/待绑定筛选、客户绑定与新建、快捷回复、AI 回复草稿、附件收发、自动翻译和按天跟进同步；客户自动匹配遵守账号隔离。
- 世界地图：展示所有已成交客户的国家及成交数量。
- 全局提醒角标：库存不足、待跟进超期、公共客户池数量等。

| 账号管理 | 新增账号、停用/启用、重置密码、修改当前账号密码 |

| 访问方式 | 电脑浏览器、手机浏览器、微信内网页（H5）；手机端已做响应式适配 |

## 5. 关键业务规则汇总

| 规则 | 内容 |
|---|---|
| 库存回补（V1.01） | 扣减时库存 ≤ 0 → 完成发货后回补该次扣减；扣减时库存 > 0 → 完成发货后不回补 |
| 跟进超期 | 满 29 天未跟进 → 强提醒；满 30 天 → 自动进入公共客户池（仅限有过跟进记录的客户） |
| 跟进独立 | 跟进记录按登录账号隔离，仅本人可见 / 可操作 |
| 公共客户池 | 取消跟进或超期自动入池；全员可见；领取后回到客户管理并生成领取跟进 |
| 单据单价 | 单价以用户在单据明细中输入为准，系统不自动套用历史价 / 参考价 |
| 总箱数 | PI 的「总箱数」= 明细各行 CTN 之和 |
| 单据金额 | 金额 = 数量 × 单价；单据合计 = 各行金额之和 |
| 货款欠款 | 欠款（未付）= 单据金额 − 已付（已付 = 分笔收款合计） |
| 发货与收款 | 登记过收款（含仅收定金）的 PI 可进入发货流程 |
| 国家识别 | 按国际区号匹配国家/地区；+1 属北美共用，自动填美国，加拿大需手动选择 |
| 单据打印 | 所有列压缩在一页宽度内；纵向内容自然分页且不重复；表头只在首页出现 |

## 6. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 局域网内 10 人以内并发使用流畅；单据列表分页；单表数据量万级以内 |
| 兼容性 | Chrome / Edge 最新版；手机端（iOS / Android）浏览器与微信内置浏览器适配 |
| 安全 | HTTPS（云部署自动证书）、账号密码登录、会话有效期 30 天、可停用账号 |
| 可靠性 | 启动自动备份数据库；每日定时备份；数据迁移支持整库上传 |
| 可维护性 | 代码备份便于回滚；服务日志可查；PM2 进程守护自动重启 |
| 可扩展性 | 支持接入外部获客工具（Google 地图采集、B2B 线索工具）与 AI 接口 |

## 8. 已知限制与后续规划

### 8.1 已知限制

- 数据库为 SQLite 单文件，适合小团队；高并发 / 多节点部署建议迁移到 MySQL / PostgreSQL。
- “PI 与采购单产品匹配”目前按产品编号优先、品名 / 型号文字兜底，命名不一致时可能误判。
- 微信小程序需 web-view 壳（要求企业主体 + HTTPS + 备案域名）或原生重写，当前采用微信内网页（H5）方案。
- WhatsApp 使用非官方 Baileys 协议，存在账号风控风险；企业正式环境应评估 WhatsApp Cloud API 等合规通道。
- Codex 助理按本机 Codex CLI 的认证方式计费；DeepSeek 与获客工具按各自 API 规则计费。

### 8.2 后续规划（建议）

- 客户负责人 / 分配规则：领取公共池客户后自动归属到领取人，并支持主管查看全团队数据。
- 自动跟进提醒：到期当天推送（微信 / 邮件）提醒业务员。
- 数据看板：按业务员统计跟进量、成交转化率、客户来源分析。
- 数据库升级：支持 MySQL 与云数据库，支持多实例部署。
- 获客渠道打通：Google 地图采集 / 第三方线索工具 → 线索池 → 一键转客户。

## 9. 部署方式与验收要点

### 9.1 部署方式

| 方式 | 说明 |
|---|---|
| 本机 / 局域网 | 运行 `启动系统.bat`，监听 `0.0.0.0:5000`；防火墙放行 5000 端口；同网段设备访问 `http://本机IP:5000` |
| 云服务器 | 上传代码包 / 完整数据包 → 执行 `deploy/install-server.sh 域名` → Caddy 自动 HTTPS + PM2 守护 |
| 微信内访问 | 手机微信打开 `https://域名`；可放入公众号自定义菜单（需认证公众号） |

### 9.2 验收要点

- 账号可正常登录；不同账号的跟进记录互不可见、互不可改。
- 客户「取消跟进」后进入公共客户池，其他账号可见并可领取；领取后生成领取跟进。
- 满 29 天未跟进客户出现在强提醒面板与角标；满 30 天自动入池并在公共池可见。
- 单据明细支持分类 / 货号添加产品、自动带出每箱件数、保存后单价金额正确。
- PI 打印 / 导出：所有列在一页宽内、无重复内容、总箱数正确、备注图片显示。
- 货款分笔收款汇总正确；已收款 PI 出现在发货与待发货列表；未收齐订单出现在待收款面板。
- 库存扣减 / 回补符合 V1.01 规则；库存流水可追溯。
- 数据库每次启动自动备份；云部署 HTTPS 可访问。
