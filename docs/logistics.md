# 物流跟踪（已上线）

> 供应链下的双向物流台账：**供应商发货**（供应商 → 我司/货代）和**客户出货**（我司 → 客户）。
> 手工录入，到点提醒你查进度。不接任何付费查询接口。

## 一、为什么这样设计

一张物流单（一票货）经常装着**好几个客户**的货，每家的箱子上有自己的**唛头**、对应各自的**订单号**。
所以数据分两层：

```
运单 logistics_shipments（一次实际发货）
  ├─ 分票 logistics_items（客户A + PI-2026-001 + 唛头 ALPHA/C + 5000pcs）
  ├─ 分票 logistics_items（客户B + PI-2026-002 + 唛头 NORDIC/C + 3000pcs）
  └─ 轨迹 logistics_events（几点到哪、什么状态）
```

一张运单可以只有一条分票（整柜单一客户），也可以十几条（拼柜多客户）。

## 二、怎么用

### 新建运单

菜单 **供应链 → 物流跟踪 → 新建运单**，填：

- **方向**：客户出货 / 供应商发货
- 运单号、承运商（自由填写：顺丰 / DHL / 美森 / 货代名）
- 发货日期、预计到达、状态
- 发货方 / 收货方、整单参考号（合同号/客单号，可空）、运费
- **隔几天提醒我查物流**（默认 2 天）
- **物流单图片**：面单 / 装箱单 / 货物照片，可多张（单张 ≤3MB，点缩略图看大图）

下面「分票明细」按客户/订单一行行填：客户、供应商、订单号、唛头、品名、数量、箱数。整单只有一个客户就填一行；只是想记个运单号、不填分票也行。

**客户 / 供应商可以直接打字**（不用先建客户）：

- 输入时下拉会提示系统里已有的名字，选中即关联到该客户/供应商；
- 手打一个系统里没有的名字 → 按"手填"存下来，详情页会标一个「手填」小标签；
- 服务端会做一次匹配：精确名称 → 模糊唯一 → 都对不上才存文本。所以先手填、以后再建客户，名字一致就会自动对上号。

### 日常

- **列表**：按方向、状态、关键字（单号/订单号/唛头/品名）筛选。**到期的行会整行标黄**，下次查询日变红。
- **详情**：顶部有"该查物流了"的提示条，可以「推迟 1 天 / 2 天」；右侧「更新进度」记一笔（状态 + 位置 + 备注），记完自动把提醒往后推 N 天。
- **仪表盘**：到期的运单会出现在「物流待查询」卡片里，带两个快捷按钮——**到了**（标记已到港）和**推迟**（2 天后再提醒）。

## 三、提醒规则

| 情况 | 下次提醒 |
| --- | --- |
| 新建运单 | 发货日 + N 天（默认 2） |
| 记一笔轨迹 | 今天 + N 天 |
| 点了「推迟」 | 今天 + 推迟天数 |
| 状态改为 **已签收 / 已取消** | 清空，不再提醒 |

提醒出现在两个地方：**左侧菜单角标**（红色数字）和**仪表盘顶部卡片**。没有后台定时任务，纯粹在页面渲染时计算，零开销、不会漏。

## 四、数据表

| 表 | 内容 |
| --- | --- |
| `logistics_shipments` | 运单：方向、单号、承运商、状态、收发方、日期、运费、`check_days`、`next_check_at`、`images`（物流单图片 JSON） |
| `logistics_items` | 分票：运单ID、客户/供应商、单据号、订单号、唛头、品名、数量、单位、箱数 |
| `logistics_events` | 轨迹：时间、状态、位置、备注、记录人 |
| `uploads/logistics/` | 运单图片（面单/装箱单照片），编辑时可删可加 |

## 六、为什么不用现成的物流查询 API

| 方案 | 问题 |
| --- | --- |
| [Karrio](https://pypi.org/project/karrio-server/)（自托管统一物流 API） | 要另起 Python 服务 + 每家承运商密钥，对单机内网 CRM 太重 |
| [ts-shipment-tracking](https://github.com/0xA-10/ts-shipment-tracking) | 只覆盖 FedEx/UPS/USPS，且要官方 API key |
| 17TRACK / 快递100 | 按查询计费，还要处理配额和失败重试 |

所以：**台账自己做，查询交给业务员**——详情页有「复制单号」和「去 17TRACK 查」两个按钮，点开就是官网实时轨迹。等你真觉得手动查烦了，再按 `src/logistics.js` 加一个 `fetchTracking()` 适配器接 17TRACK 即可，表结构不用动。

## 七、已知限制

- 不支持自动抓取轨迹（见上）。
- 分票不自动关联单据表（`doc_id` 预留了字段，暂时手填订单号）。
- 一张运单不能拆成多次发货（真拆了就再建一张运单）。
- 图片只存原图不压缩，单张上限 3MB；手机拍的 5MB 原图请先截一下或压缩再传。
