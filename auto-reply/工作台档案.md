# 工作台档案 — 外贸客户自动回复

> 版本 v2.0 ｜ 更新日期 2026-11-16 ｜ 状态：已搭建 v2 资格判定版，待用户填 cookie + 放画册素材 + 观察验证

## 1. 使用场景

- **核心流程**（v2）：FB 投流客户发来新消息 → v1 安全闸门 → **AI 判定语言/目的/精准度** → 精准则按目的发素材（画册/报价/现货图）；信息不足追问（≤2轮）；不精准放弃。
- **业务背景**：FB 投流询盘来源不精准，必须先筛选"是否曾从中国公司采购过"，再决定是否投入素材。
- **触发频率**：消息驱动（轮询 15 秒），全天运行。
- **硬性规则**：已置顶客户一律不回；人工已回的不抢话；未判定精准不发素材。

## 2. 页面清单

无独立前端，全部后台进程 + 日志：

| 组件 | 文件 | 说明 |
|---|---|---|
| 主控进程 | `worker.js` | 轮询、闸门、判定状态机、素材分发、发送、记账 |
| 资格判定 | `qualify.js` | AI 判定（读 settings 的 ai_api_key），输出语言/目的/精准度/回复；v2.3 起读 `icebreakers.md` 按场景取 1–2 条破冰打法进提示词，并可生成跟进内容 |
| 破冰打法 | `icebreakers.md` | 销售破冰话术与跟进打法（人看 + AI 用），末尾带场景标签的打法摘要 |
| 决策逻辑 | `logic.js` | 纯函数（v1 闸门 + v2 状态机 + 跟进判定），可独立自测 |
| 自测脚本 | `selftest.js` | 108 项断言，不发消息不调 AI |
| 启动器 | `start.bat` | 双击启动，Ctrl+C 停止 |
| 配置 | `config.json` | 所有开关、阈值、素材路径 |
| 素材目录 | `materials/` | 用户放画册/报价；`materials/stock/` 放现货图（可选） |
| 文本日志 | `auto-reply.log` | 运行日志（运行时生成） |
| 状态库 | `state.db` | 游标/资格状态/冷却/额度/日志/跟进状态（运行时生成） |

## 3. 数据源清单

| 数据源 | 位置 | 用途 | 权限 |
|---|---|---|---|
| `wa_messages` / `wa_chats` / `wa_accounts` / `sessions` | 主库 `data/crm.db` | 新消息、置顶/群聊判断、账号归属、cookie 解析 | 只读 |
| `products.image` | 主库 | 现货图片路径 | 只读 |
| `quote_history` | 主库 | 历史报价产品（精准度强信号、客户档案补充） | 只读 |
| `settings.ai_api_key` / `ai_model` | 主库 | v2 判定复用主系统 DeepSeek Key | 只读 |
| `/api/wa/draft` | 主系统 HTTP | v1 模式生成回复（v2 不用） | cookie |
| `/whatsapp/send` | 主系统 HTTP | 发文本 + multipart 发文件 | cookie |

**关键事实**：系统无现成画册（documents 只有报价/PI/SO 等 6 类，无 catalog）；无"是否采购过中国"字段 → 精准度靠 AI 从对话推断 + 主动追问。画册文件由用户放 `materials/`。

## 4. 自动化规则

### v1 闸门（强制，不可关）
| 规则 | 默认 |
|---|---|
| 置顶跳过 | 强制 |
| 人工优先（最后一条 from_me=1 则跳过） | 强制 |
| 发送前二次确认（置顶/人工竞态） | 强制 |
| 素材包逐条复查置顶（发到一半被置顶就停） | 强制 |

### v2 资格判定与目录规则（v3.0）
| 规则 | 参数 | 默认 |
|---|---|---|
| 要目录的新客户不直接发全套 | — | 追问（一次一问），报采购量 / 要样品或视频看厂 / 判精准 → 转人工；没给具体需求继续挖，最多 6 轮，到上限转人工并附已挖到的信息摘要 |
| 客户给出具体需求转人工 | `notifications` 表 + `/api/notifications` | 右下角强弹窗 + 铃铛未读数，弹窗常驻到点【知道了】，【去跟进】跳 WhatsApp 会话；24 小时内同一会话同类通知只留一条；低精准/风险/挖满 6 轮仍不明的不弹 |
| 老客户要目录/报价/现货 | — | 直接发素材，不走三个问题 |
| 挑款按产品定位字段 | `positioning` | 高端款 / 高流通款 / 空（不参与自动挑款），不按材质推断 |
| 主动跟进（只跟未置顶） | `followup.enabled` | `true` |
| 跟进间隔 / 首跟窗口 | `minSilenceHours` / `maxSilenceHours` | 24 小时 / 72 小时 |
| 每轮静默最多跟进次数 | `maxFollowups` | 2 次（不含收尾） |
| 满次数后礼貌收尾 | `sendClosing` | `true`，发完不再打扰 |
| 明确拒接抑制期 | — | 14 天内不再跟进 |
| 破冰打法 | `icebreakers.md` | 判定与跟进提示词按场景取 1–2 条 |

### v2 资格判定
| 规则 | 参数 | 默认 |
|---|---|---|
| 资格判定开关 | `qualify.enabled` | `true` |
| 追问轮数上限 | `maxQualifyRounds` | 6 |
| 素材分发 | `sendMaterialPackage` | `true` |
| 画册文件 | `catalogFile` | 空（自动取目录第一个PDF/图片） |
| 现货来源 | `stockFromProducts` | `true`（从 products 表取图） |
| 单次现货图上限 | `maxStockImages` | 3 |
| 总开关（观察/发送） | `enabled` | `false` |

### 通用刹车
冷却 10 分钟 / 每日额度 40 / 群聊跳过 / 群聊需绑定客户(否) / 首次保护(只回新消息) / 轮询 15 秒。

**幂等**：`wa_messages.id` 游标 + `qualification` 状态表双重记账，重启/重连不重复发送、不重复追问。

## 5. 权限说明

- **密钥存放**：`config.json` 的 `sessionCookie`（crm_sid）；AI Key 复用主库 `settings`（不落本目录、不硬编码）。
- cookie 有效期 30 天，过期需重抓。
- **权限最小化**：数据库只读；发送走主系统现有接口受账号权限约束；只处理 cookie 账号名下会话；AI 凭证只读不写。
- 当前 `sessionCookie` 为空，待用户填写。
