# HQ CRM 微信小程序上线部署手册

> 本手册对应的全部新增内容都在 `miniapp/` 文件夹内，**未修改系统任何源文件**。
> 小程序端与网页版共用同一个数据库 `data/crm.db`，数据实时一致。

---

## 一、整体架构

```
微信小程序（miniapp/wechat）
        │  HTTPS 请求（Bearer Token 鉴权）
        ▼
你的域名（https，nginx 反向代理，云服务器 443 端口）
        │
        ├── /            ──►  CRM 网页版   127.0.0.1:5000（server.js，原有系统）
        └── /mp-api/     ──►  小程序API    127.0.0.1:5100（miniapp/mp-api/server.js）
                                      共用 data/crm.db（SQLite，WAL 模式，支持多进程）
```

小程序 V1 已实现：登录、工作台（统计/待跟进/最近单据）、客户列表与详情（联系人/跟进记录/一键拨打复制）、产品库、单据中心（六类单据筛选查询）。

## 三、服务器部署步骤

### 1. 安装 Node.js（22+）与 pm2

```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo bash -
sudo apt install -y nodejs
sudo npm i -g pm2
```

### 2. 上传项目

把整个项目文件夹上传到服务器，例如 `/opt/crm/`（可用 WinSCP/scp）。确认以下文件存在：

```
/opt/crm/server.js            # 网页版（原有）
/opt/crm/src/                 # 后端源码（原有）
/opt/crm/data/                # 数据目录（本地调试过的话，把 crm.db 一起传上去）
/opt/crm/miniapp/mp-api/server.js   # 小程序API（新增）
```

### 3. 用 pm2 启动两个服务

```bash
cd /opt/crm
pm2 start server.js --name crm-web                 # 网页版 5000
pm2 start miniapp/mp-api/server.js --name crm-mp   # 小程序API 5100
pm2 save && pm2 startup                            # 开机自启
```

### 4. 安装 nginx 并配置反向代理 + HTTPS

```bash
sudo apt install -y nginx certbot python3-certbot-nginx
sudo certbot --nginx -d 你的域名        # 自动配置 HTTPS 证书并续期
```

nginx 站点配置（`/etc/nginx/sites-available/crm`）：

```nginx
server {
    listen 443 ssl;
    server_name 你的域名;

    # 反向代理：网页版
    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # 反向代理：小程序API
    location /mp-api/ {
        proxy_pass http://127.0.0.1:5100/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

启用并重载：

```bash
sudo ln -s /etc/nginx/sites-available/crm /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

验证：浏览器打开 `https://你的域名/mp-api/api/mp/ping`，应返回 `{"ok":true,...}`。

> 防火墙/安全组：只需放行 80 和 443，**5000、5100 不要对公网开放**。

## 四、小程序端配置

1. 编辑 `miniapp/wechat/utils/config.js`，把服务地址改为正式域名：

```js
const BASE_URL = 'https://你的域名/mp-api';
```

2. 编辑 `miniapp/wechat/project.config.json`，把 `appid` 改为你的小程序 AppID（注册后在小程序后台「开发管理 → 开发设置」查看）。

---

## 五、注册微信小程序账号

1. 打开 mp.weixin.qq.com → 立即注册 → 选择「小程序」。
2. 主体类型：
   - **企业 / 个体工商户**：需要营业执照、对公账户验证，功能限制最少，推荐；
   - **个人**：可以注册，但部分类目受限（本 CRM 以「工具类」上线个人主体通常可行）。
3. 类目建议：**工具 → 效率 / 信息查询** 或 **企业服务**。
4. 注册完成后，在「开发管理 → 开发设置」获取 **AppID**，并生成「开发者密钥」备用。

## 六、开发调试 → 上传审核 → 发布

### 1. 本地调试

1. 双击 `miniapp/启动小程序API服务.bat`（本机 5100）；
2. 微信开发者工具 → 导入项目 → 选择 `miniapp/wechat` 文件夹；
3. 详情 → 本地设置 → 勾选 **「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**；
4. 用网页版相同账号登录测试（开发阶段可先把 `config.js` 改回 `http://127.0.0.1:5100`）。

### 2. 配置合法域名（上线前必做）

小程序后台 → 开发管理 → 开发设置 → **服务器域名 → request 合法域名**，添加：

```
https://你的域名
```

（每月可修改次数有限，注意一次填对。）

### 3. 上传与发布

1. 开发者工具右上角 **「上传」**，填写版本号（如 1.0.0）和备注；
2. 小程序后台 → 版本管理 → **开发版本 → 提交审核**；
3. 审核通过后（一般 1~2 天）→ **发布**，用户即可搜索使用。

> 提审时建议在「版本描述」说明：本工具为公司内部客户管理工具，登录需账号密码，无违规内容。

## 七、安全与维护建议

- **修改默认密码**：网页版 admin/admin123、sales/sales123 上线前务必改掉；
- **数据备份**：定期备份 `/opt/crm/data/crm.db`（可用 crontab 每日复制一份）；
- **不要暴露 5000/5100 端口**，全部走 nginx 443；
- 小程序 API 只读为主（登录/查询），后续需要小程序端新增/编辑数据时，在 `miniapp/mp-api/server.js` 中按同样模式扩展接口即可。

## 八、常见问题

| 现象 | 原因与解决 |
| --- | --- |
| 登录提示「网络连接失败」 | `config.js` 地址写错 / 服务器 5100 未启动 / nginx 未配置 /mp-api |
| 提示「不在以下 request 合法域名列表中」 | 后台未配置合法域名，或开发工具未勾选「不校验合法域名」 |
| 提示「未登录或登录已过期」 | token 过期（30 天），重新登录即可 |
| 提示「用户名或密码错误」 | 使用网页版相同账号；密码可在网页版「系统设置」修改 |
| 小程序审核被拒 | 类目不符：改用「工具-效率」类目；或补充说明为内部管理工具 |
